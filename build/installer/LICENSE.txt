2. POLÍTICA DE PRIVACIDADE

2.1. COLETA DE DADOS
O Sistema coleta e processa os seguintes tipos de dados:
• Dados de autenticação (e-mail, senha criptografada)
• Informações de perfil (nome completo, foto de perfil)
• Dados operacionais (clientes, produtos, serviços, vendas)
• Dados de comunicação (mensagens do chat interno)
• Metadados de uso (logs de acesso, ações realizadas)

2.2. USO DOS DADOS
Os dados coletados são utilizados para:
• Autenticação e controle de acesso ao Sistema
• Processamento de operações comerciais e administrativas
• Comunicação interna entre usuários
• Análise de desempenho e melhorias do Sistema
• Cumprimento de obrigações legais e regulatórias

2.3. ARMAZENAMENTO E SEGURANÇA
• Todos os dados são armazenados em servidores seguros com criptografia
• Senhas são armazenadas usando hash criptográfico (bcrypt)
• Implementamos medidas técnicas e organizacionais para proteger os dados
• Acesso aos dados é restrito apenas a pessoal autorizado
• Realizamos backups regulares para garantir a integridade dos dados

2.4. COMPARTILHAMENTO DE DADOS
Os dados NÃO são compartilhados com terceiros, exceto:
• Quando exigido por lei ou ordem judicial
• Para prestadores de serviço essenciais (infraestrutura cloud)
• Com consentimento expresso do titular dos dados

2.5. DIREITOS DO USUÁRIO
Você tem o direito de:
• Acessar seus dados pessoais armazenados no Sistema
• Solicitar correção de dados incorretos ou incompletos
• Solicitar exclusão de dados (sujeito a obrigações legais)
• Exportar seus dados em formato estruturado
• Revogar consentimento para processamento de dados

2.6. COOKIES E ARMAZENAMENTO LOCAL
O Sistema utiliza armazenamento local (IndexedDB, localStorage) para:
• Manter sessão de usuário autenticado
• Cache de dados para funcionamento offline
• Preferências de interface e configurações do usuário

2.7. RETENÇÃO DE DADOS
• Dados operacionais: mantidos indefinidamente para fins contábeis e legais
• Dados de usuários inativos: mantidos por 5 anos após última atividade
• Logs de sistema: mantidos por 12 meses
• Backups: mantidos por 30 dias com rotação automática

2.8. TRANSFERÊNCIA INTERNACIONAL
Os dados podem ser armazenados em servidores localizados fora de Moçambique,
especificamente em data centers da Supabase (Estados Unidos e Europa), que
aderem a padrões internacionais de proteção de dados.

2.9. SEGURANÇA INFANTIL
O Sistema não é destinado a menores de 18 anos. Não coletamos intencionalmente
dados de menores. Se tomarmos conhecimento de coleta inadvertida, os dados serão
imediatamente deletados.

2.10. ALTERAÇÕES NA POLÍTICA
Esta Política de Privacidade pode ser atualizada periodicamente. Mudanças
substanciais serão comunicadas aos usuários através do Sistema. O uso continuado
após alterações constitui aceitação das novas políticas.
