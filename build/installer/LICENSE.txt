2. POLITICA DE PRIVACIDADE

2.1. COLETA DE DADOS
O Sistema coleta e processa os seguintes tipos de dados:
- Dados de autenticacao (e-mail, senha criptografada)
- Informacoes de perfil (nome completo, foto de perfil)
- Dados operacionais (clientes, produtos, servicos, vendas)
- Dados de comunicacao (mensagens do chat interno)
- Metadados de uso (logs de acesso, acoes realizadas)

2.2. USO DOS DADOS
Os dados coletados sao utilizados para:
- Autenticacao e controle de acesso ao Sistema
- Processamento de operacoes comerciais e administrativas
- Comunicacao interna entre usuarios
- Analise de desempenho e melhorias do Sistema
- Cumprimento de obrigacoes legais e regulatorias

2.3. ARMAZENAMENTO E SEGURANCA
- Todos os dados sao armazenados em servidores seguros com criptografia
- Senhas sao armazenadas usando hash criptografico (bcrypt)
- Implementamos medidas tecnicas e organizacionais para proteger os dados
- Acesso aos dados e restrito apenas a pessoal autorizado
- Realizamos backups regulares para garantir a integridade dos dados

2.4. COMPARTILHAMENTO DE DADOS
Os dados NAO sao compartilhados com terceiros, exceto:
- Quando exigido por lei ou ordem judicial
- Para prestadores de servico essenciais (infraestrutura cloud)
- Com consentimento expresso do titular dos dados

2.5. DIREITOS DO USUARIO
Voce tem o direito de:
- Acessar seus dados pessoais armazenados no Sistema
- Solicitar correcao de dados incorretos ou incompletos
- Solicitar exclusao de dados (sujeito a obrigacoes legais)
- Exportar seus dados em formato estruturado
- Revogar consentimento para processamento de dados
